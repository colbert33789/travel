# 第三方数据条款

本项目代码为 [MIT](https://github.com/colbert33789/travel/blob/main/LICENSE) 许可，
但**调用到的第三方数据归各自权利方所有，不在 MIT 范围内**。使用本项目前请确认你遵守下列条款。

## 各数据源条款

| 数据源 | 归属 | 约束 |
|---|---|---|
| 百度慧眼迁徙 | 百度 | 公开页面数据，受百度开放平台条款约束；不得用于商业分发 |
| 百度地图 Place 2.0 | 百度 | 需 `BAIDU_MAP_AK`，受配额限制（本项目的住宿检索数上限 150） |
| 高德开放平台（路况/驾车规划/POI） | 高德 | 需 `AMAP_KEY`，Web 服务 Key 有日配额与 QPS 限制 |
| 腾讯位置服务（驾车路线规划） | 腾讯 | 需 `TENCENT_MAP_KEY`，日额度耗尽后本项目自动停止请求 |
| 12306 余票 | 中国铁路 | 仅用于查询公开余票；请控制频率，勿高频抓取 |
| 七普人口 | 国家统计局 | 公开统计数据，引用请注明来源 |

## 内置快照

`src/holiday_traffic/reference/baidu_snapshot.json` 是**百度慧眼公开数据的快照**，
仅用于离线兜底与结果复现（断网时让流水线仍能跑通、结果可复现）。

- 不得作为商业数据分发或转售
- 文件体积小（141KB），只含项目所需字段与必要日期范围
- 需要更新时用 `scripts/update_reference.py` 重新采集

## 模拟值与代理指标

以下字段**不是真实平台数据**，报告与 API 中均如实标注，请勿当作真实指标引用：

- `social_heat.csv`（小红书/抖音/微信）：人工先验 + 模拟演化，**非真实帖子热度**
- `ota_signals.csv`（携程/去哪儿/美团/飞猪）：先验推导，**非真实房价、库存或预订量**
- `lodging_supply.csv` / `baidu_lodging_supply.csv`：地图**地点供给代理**（近 5km POI 检索数），
  **非客房数、非订单量**；高德 18/41 地点返回恰好 600（疑似检索上限），此时仅作下界；
  两者口径不同，**计数不可相加或按比例换算**

## 密钥

`AMAP_KEY` / `BAIDU_MAP_AK` / `TENCENT_MAP_KEY` 属个人凭证：

- 只写入项目根 `.env`（已被 `.gitignore` 忽略）或环境变量，**不要提交到版本库**
- `chmod 600 .env` 可防止本机其他用户读取
- 如不慎泄露，请到对应平台控制台立即重置
