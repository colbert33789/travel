# 方法论

原则：**真实数据优先，假设显式化，精度用真实历史回测说话。**

## 1. 数据分层

| 层 | 来源 | 性质 | 用途 |
|---|---|---|---|
| 深圳迁出/迁入规模 | 百度慧眼 `historycurve`（免 Key） | **真实**，T+1 | 出行节奏、在外人数、高速流量输入 |
| 深圳假期去向城市占比 | 百度慧眼 `cityrank` | **真实** | 去向分布、结构回测 |

## 2. 模型

### 2.1 出行节奏（总量层）

```
逐日规模指数 = 预测年平日基线 × 参考年节奏倍数
平日基线   = 9/1–9/20 均值（避开 2026-09-25 中秋与节前提前出行）
节奏倍数   = 2024/2025 国庆逐日指数 ÷ 各自平日基线，取均值；区间取两年极值
对齐方式   = 两端对齐（k=0 节前一天、k=n_days 假期末日、k=n_days+1 节后首日）
              参考年假期长度 ≠ 目标年时(2025 为 8 天)，长度差落在假期中段
实时修正   = 已公布日直接用实测替换，最近偏差按 0.6^k 衰减传递给后续日
             同时同步修正区间：已实测日区间收窄为该点，后续日上下界按同一衰减系数平移
```

由真实数据得到的关键事实（也是对早期版本假设的纠正）：深圳迁出在 D1 达峰（≈平日 3.8 倍），之后**单调回落**；返程高峰体现在**迁入**（D6–D7 ≈平日 2.6–2.8 倍）。

### 2.2 深圳在外人数（守恒）

超额迁出（高于平日部分）为离开，超额迁入按时序分布为返回；用二分求返程缩放系数，使「走多少回多少」严格成立（期末存量归零）。

### 2.3 目的地拥挤度

对每个目的地城市，用其**全来源**迁入/迁出曲线（深圳在远途目的地客源中仅占 8–15%，只算深圳会严重低估）：

```
外来到达_k   = 超额迁入_k × (1 − k/(n+1))        前段迁入主要是外来者
外来存量 V_k = V_{k−1}·(1 − 1/2.5) + 外来到达_k   存量-流量模型，平均停留 2.5 天
外出本地人 L = 超额迁出前段离开、超额迁入后段返回，守恒闭合
游客        = τ_c × V                            τ_c：旅游占比先验（劳务输出城市以返乡为主）
城内分配    ∝ 接待能力 × 旅游吸引力 × 社媒^0.6 × OTA^0.8（未收录城区按 0.6 吸引力计）
拥挤度      = 游客 ÷ 接待能力（客房 × 2.8 人/间 × 1.6 弹性）
```

分级：<60% 舒畅 · 60–85% 正常 · 85–100% 较拥挤 · 100–120% 拥挤 · ≥120% 严重拥挤。

### 2.4 高速拥堵

LightGBM 分位数回归（P10/P50/P90），特征：当日超额出行/返程量（真实剖面）、出城/返程方向、小时节律、路段、天气预报、线路 OTA 热度。训练样本为仿真（见 §1），因此**只提供相对强弱与时段形态**。
实时校准：假期当天若配置高德 Key，用实测车速（TTI ≈ 90 km/h ÷ 实测车速）校准当日剩余小时，比例限幅 [0.8, 1.25]、逐小时 0.85 衰减；不在假期窗口内不校准。

仿真采用**乘性分解**，保证量纲与物理边界：

```
TTI = 平日基线 × 日内形态 × (1 + (假期峰值系数 − 1) × 假期压力) × 观测噪声(±6%)
日内形态 = 广州 214 路段实测车速折算的逐时拥堵系数(周末), 归一后均值 1(夜间 ≈0.83, 午后峰 ≈1.18)
假期压力 = 当日强度 × 时段形状 × 走廊需求 × 天气 × 年际波动, clip [0, 1.3]
          当日强度 ∝ 当日假期诱发流量(真实剖面), ∈[0.3, 1]
          时段形状 = 出城峰(10 时)/返程峰(18 时)高斯叠加实测日内起伏, 峰值归一为 1, 夜间地板 0.05
```

由此夜间（压力→0.05）TTI ≈ 平日基线 × 0.83 ≈ 1.2（基本畅通），峰值日峰值时（压力→1）≈ 平日基线 × 1.08 × 峰值系数 ≈ 2.8–3.2（严重拥堵），与高德国庆报告口径一致。

**区间校准**：预测目标年存在训练期看不到的年际波动，直接用分位数回归输出的 P10/P90 会系统性偏窄（检验集实测覆盖 68%）。故采用三段式：训练（前 n−2 年）→ **保形分位校准**（Conformalized Quantile Regression, Romano et al. 2019，用倒数第 2 年的 `(P10−y)` 与 `(y−P90)` 的 90% 分位数作双侧平移）→ 检验（最后一年）。校准后覆盖率回到名义 80%。

### 2.5 社媒种草-拔草动力学

`H(t+1) = H + 0.55·H·(1−H/0.95) − 0.8·max(0, 拥挤度−1)·H`，热度通过 `1 + 0.4·(H−0.5)` 调节城内分配。初值为先验（平台无公开 API）。

### 2.6 推荐与多日行程

逐日榜隐含「当天往返」假设（车程扣分按每天一次往返计）。规划 2–3 天自驾游时
改用 `recommend.trip_rank` / `scripts/itinerary.py`：**车程按天分摊**
（多日游只去一次，日均车程 = 2×单程/天数）、天气与拥挤度取区间内最不利的一天。
因此多日榜会比逐日榜更推荐稍远的目的地。

### 2.7 推荐（逐日）

```
推荐分 = 游玩性(0-100) × exp(−1.2·max(0, 拥挤度−0.85))
       − 45 × 车程h / (车程h + 3)          车程扣分(饱和, 上限 45)
       − 10 × max(0, 路线TTI − 1.3)
       − 10 × max(0, 房价溢价 − 1)
       − 5  × 降水等级 × 自然景观占比/5

车程 = 实测平日耗时 ÷ (1 + 0.5×(平日TTI − 1)) × (1 + 0.5×(路线TTI − 1))
```

三处工程要点：

- **车程用实测路网，不用球面距离估算**（`geo.ROAD_MEASURED`，高德驾车路径规划 API 于 2026-09-29 实测 40/40 成功）。珠江西岸必须绕珠江口（虎门大桥 / 深中通道），「球面距离 × 1.3」会系统性低估：

  | 目的地 | 球面×1.3 | 实测 | 偏差 |
  |---|---|---|---|
  | 珠海市区 | 76 km | **109.5 km** | −34 |
  | 珠海万山(外伶仃岛) | 81 km | **132.3 km** | −51 |
  | 汕头南澳岛 | 413 km | **367.8 km** | +46 |

  车程直接决定推荐分里的时间成本，低估会让西岸目的地被排得虚高。

- **自由流速度由实测标定**：24 个 ≥150 km 的长途样本合计 6919 km / 87.0 h，综合均速 **79.5 km/h**（含两端市区段），远低于原先假设的 95 km/h。实测耗时含平日拥堵，故先除以平日拥堵系数（`WEEKDAY_TTI=1.30`）反推自由流耗时，再乘假期拥堵系数；拥堵延时只作用于易堵段落（出入城 + 瓶颈，取 50%），否则 300 km 行程会被整程按拥堵车速折算而严重高估。

- **车程扣分取饱和形式** `h/(h+3)`：边际厌恶递减（3h 与 4h 的体验差距小于 1h 与 2h），且保证扣分有界，避免远途目的地把全表推荐分压成负数（修复前 Top1 为 −3.9 分）。

一处需要读者注意的语义：**拥挤折减只在承载率 > 0.85（「正常」级上界）时才生效**，即不惩罚「正常范围内的人多」。因此推荐前列的平均拥挤度并不低于全表平均（实测 Top3 为 0.40、全表 0.31）—— 它优化的是「好玩 + 近 + 便宜 + **不严重**拥挤」，而非「越不挤越好」。真正想避挤的读者应看报告的「💎 人少又好玩」专栏（筛选条件：峰值承载率 < 0.6 且游玩性 ≥ 60）。

## 3. 准确度（真实数据留一年回测）

| 对象 | 方法 | 结果 |
|---|---|---|
| 深圳逐日迁出/迁入 | 2024↔2025 互测 | MAPE 17.1% / 12.8%，**高峰日命中 100%** |
| 21 个目的地逐日迁入 | 同上，42 城-年 | MAPE 中位 29.3% |
| 深圳去向城市占比 | 2024 预测 2025 | MAE 0.52pp（辐射模型先验 2.29pp） |
| 拥堵 TTI | 仿真自洽（训练 2021-23 → 校准 2024 → 检验 2025） | MAPE 5.2%，80% 区间覆盖 80–81%（校准前 68%），仅说明模型学会了设定规律，**不代表真实路况精度** |

解读：2025 年为 8 天假期且含中秋，逐日数值差异大，但峰值日稳定——预测的「哪天最挤」比「具体多少人」更可靠。只有两个参考年，区间偏窄，应视为下限不确定性。

## 4. 已知局限与假设清单

- `people_per_index = 4.5`（万人次/指数点）为量级校准假设：**不改变**日间/地点排序，但线性缩放拥挤度绝对值，因此会改变**拥挤度分级**（舒畅/正常/较拥挤/拥挤/严重拥挤）——而分级是报告「哪里人最多」的主要输出。有深圳交通局官方「出深人次」口径后应重新标定。
- τ_c（旅游占比）、客房存量、平均停留 2.5 天、前后段分解权重均为先验，可用各市国庆文旅统计公报校准。

### 敏感性分析（先验参数扰动）

对上述未标定先验做扰动，观察「最拥挤 Top3 / 推荐 Top3 / 拥挤度峰值」的变化：

| 扰动 | 最挤 Top3 | 推荐 Top3 | 峰值拥挤度 |
|---|---|---|---|
| 基准 | 鼎湖山、连州地下河、欧家梯田 | 鼎湖山、博罗县、南沙区 | 1.31 |
| τ_c × 1.25 | 不变 | 不变 | 1.63 |
| 平均停留 2.5 → 2.0 天 | 不变 | 不变 | 1.28 |
| 平均停留 2.5 → 3.5 天 | 不变 | 不变 | 1.33 |
| `people_per_index` → 3.5 | 不变 | 不变 | 1.02 |
| `people_per_index` → 6.0 | 不变 | 不变 | 1.74 |
| 未收录城区吸引力 0.6 → 0.9 | 次序微调 | 不变 | 1.07 |
| 未收录城区客房密度 × 2 | **改变** | 次序微调 | 0.98 |

结论：**排序结论对先验扰动稳健**（推荐 Top3 在全部 8 个场景下不变），因此报告「去哪儿玩 / 哪里人最多」的排序可信；**拥挤度的绝对数值与分级则随 `people_per_index`、τ_c 近线性变化**，应作为量级参考而非精确值。最容易推翻结论的参数是「未收录城区的接待能力」，它决定了城市内游客在收录城镇与其余城区之间的分流比例。
- 拥堵模型无真实历史训练数据；接入高德（或交通运输部路网中心）历史数据后应替换仿真样本。
- 辐射模型（Simini et al., *Nature* 2012）仅用于回测对照：城市级误差远大于直接使用真实去向占比，故不参与城市级分配。
